# Code of conduct

Keep discussion respectful and grounded in technical facts. Everyone can
contribute without discrimination. Harassment, threats, disclosure of private
data and personal attacks are incompatible with this project.

Describe disagreements without targeting people. Report conduct concerns
privately by email to quadringent@proton.me; do not open an issue containing
sensitive information. Report security vulnerabilities as described in
[SECURITY.md](SECURITY.md).

Maintainers may request corrections, remove content or limit participation
according to severity and recurrence. Reports are handled confidentially.
Appeals may be addressed to the owner.

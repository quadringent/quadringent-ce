# Research tools

Isochronous comparisons, benchmarks, calculated reports and experimental
capture paths live here. Product runtime imports none of these modules, which
are excluded from the wheel. After `pip install -e '.[dev]'`, run
`research/scripts/` from the repository root. Their tests share pytest
collection.

Comparisons require identical positions, windows and event populations.
Synthetic or historical evidence cannot qualify a current installation.
